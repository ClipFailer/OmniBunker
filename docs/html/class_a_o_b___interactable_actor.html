Реализация взаимодействия - Сервер (Reliable) Метод вызывается если эктор реплицируется.

Аргументы
InteractorПерсонаж, который совершил взаимодействие с эктором.

Реализация взаимодействия - Сервер (Unreliable) Метод вызывается если эктор реплицируется.

Аргументы
InteractorПерсонаж, который совершил взаимодействие с эктором.

Метод, решаюший будет ли использоваться вариант RPC метода с Reliable или Unreliable Метод можно переопределять в дочерних классах, по умолчанию он возвращает true.

Возвращает
true - Вызовется метод AOB_InteractableActor::Server_Interact_Reliable | false - Вызовется метод AOB_InteractableActor::Server_Interact_Unreliable
