# OmniBunker 🏚️

**Игровой проект** на **Unreal Engine 5.7**, вдохновлённый настольной игрой «Бункер».  
Это кооперативная игра, где каждый игрок получает уникального персонажа со своими характеристиками, а цель — выжить в убежище, справляясь с испытаниями и управляя ресурсами.

Проект создаётся с упором на глубокую **систему характеристик**, **инвентарь**, **взаимодействие с объектами** и **интерфейс игрока**.

---

## 🎮 Суть игры

Игроки попадают в бункер, каждый со своим набором умений, черт и слабостей. Задача — выжить как можно дольше, сохраняя ресурсы и принимая правильные решения.

Ключевые этапы игры:
- **Знакомство** – каждый игрок изучает свою карточку персонажа.
- **Раскрытие характеристик** – игроки открывают свои черты, которые могут помочь или помешать в будущих испытаниях.
- **Мини-игры** – игрокам предстоит проходить испытания, чтобы добывать припасы (еду, оружие, технологии).
- **Голосование** – выбор, кто отправится на задание, зависит от открытых характеристик.
- **Финальный бой** – когда припасы заканчиваются, начинается борьба за выживание, и все характеристики раскрываются автоматически.

## ⚙️ Основные механики

| Механика | Описание |
|----------|----------|
| 🧑‍🤝‍🧑 **Система персонажей** | Каждый игрок получает уникальные характеристики (сила, ловкость, навыки, болезни и т.д.), которые влияют на геймплей. |
| 🃏 **Характеристики** | Характеристики могут быть скрыты или открыты. Открытые влияют на успех в мини-играх и голосовании. |
| 🗳️ **Голосование** | Игроки выбирают, кто отправится на испытание, основываясь на открытых характеристиках. |
| 🎯 **Мини-игры** | Разные испытания требуют разного количества игроков и имеют свои награды и риски. |
| 📦 **Инвентарь и ресурсы** | В бункере есть припасы (еда, оружие, технологии), которые можно добывать и расходовать. |
| 🔥 **Финальная битва** | Когда припасы заканчиваются, начинается сражение между игроками с полным раскрытием всех характеристик. |

## 🛠️ Технологии

- **Unreal Engine 5.7**
- **C++** — основная логика игры (характеристики, инвентарь, взаимодействие, состояния)
- **Blueprints** — визуальное программирование для быстрой итерации и настройки
- **Git LFS** — для хранения бинарных ассетов (текстуры, модели, звуки)
- **Data-Driven подход** — характеристики, предметы и условия вынесены в DataTables и DataAssets

## 📁 Архитектура проекта

Проект построен на модульной архитектуре. Основные папки в `Source/OmniBunker`:
```
OmniBunker/
├── Characters/ # Классы персонажей и их компоненты
├── Components/ # Переиспользуемые компоненты (характеристики, инвентарь)
├── Controllers/ # Контроллеры игроков и AI
├── Data/ # DataTables, DataAssets и структуры данных
│ ├── OB_CharacterData # Данные персонажа
│ ├── OB_CharacterCharacteristic # Характеристики
│ ├── OB_CharacteristicsPool # Пул характеристик для генерации
│ └── OB_InventoryItemData # Данные предметов инвентаря
├── Interaction/ # Система взаимодействия с объектами
│ ├── OB_Condition # Условия для взаимодействия
│ ├── OB_InteractableActor # Базовый класс интерактивных объектов
│ └── OB_InventoryActor # Акторы, которые можно подобрать в инвентарь
├── Interfaces/ # Интерфейсы для слабой связанности систем
└── UI/ # Виджеты и HUD
```

## 📥 Как скачать и запустить проект

### 1. Клонирование репозитория

```bash
git clone https://github.com/ClipFailer/OmniBunker.git
cd OmniBunker
```

### 2. Установка Git LFS
Проект использует Git LFS для хранения ассетов. Без него файлы не скачаются корректно.

Установка Git LFS:

Скачайте и установите Git LFS с официального сайта

Или через пакетный менеджер:

Windows (choco)
```
choco install git-lfs
```

# macOS (brew)
```
brew install git-lfs
```

# Linux (apt)
```
sudo apt install git-lfs
```

Инициализация LFS в репозитории:

```bash
git lfs install
git lfs pull
```

### 3. Открытие проекта
Убедитесь, что у вас установлен Unreal Engine 5.7 или выше.

Найдите в папке проекта файл OmniBunker.uproject.

Дважды кликните по нему — проект откроется в редакторе Unreal Engine.

При первом открытии может появиться предложение пересобрать модули — соглашайтесь.

### 4. Запуск игры из редактора
Нажмите кнопку Play в редакторе (или Alt + P).

Игра запустится в режиме предпросмотра.

# 📦 Сборка игры (Packaging)
Чтобы создать готовый .exe-файл для распространения:

В редакторе откройте File → Package Project → Windows → Windows (64-bit).

Выберите папку для сохранения собранной игры.

Дождитесь завершения сборки.

Готовый билд будет в выбранной папке — запускайте OmniBunker.exe.
